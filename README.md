# 🛡️ Exemplo de Spring Security

Olá! 👋 Este é um projeto de estudos focado em uma das partes mais importantes de qualquer sistema: a **Segurança**! 🔐

## 🎯 Sobre o projeto
Aqui, o objetivo é demonstrar como proteger uma aplicação construída em Java usando a tecnologia **Spring Security**. 👮‍♂️

Ele serve como um guia ou um modelo para entender como:
- 🚪 Bloquear acesso de quem não tem permissão.
- 🔑 Fazer login com usuário e senha.
- 📜 Definir quem pode ver o que (permissões de administrador, usuário comum, etc).

## 🛠️ Tecnologias Envolvidas
- ☕ **Java**: Nossa linguagem base.
- 🍃 **Spring Boot & Spring Security**: O escudo protetor da nossa aplicação! 🛡️
